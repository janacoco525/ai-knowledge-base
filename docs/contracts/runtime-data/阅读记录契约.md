# AI知识库 — 阅读记录契约

> **用途**：固定 `S2-05 阅读记录` 的最小输入、输出和诚实边界
> **更新日期**：2026-05-12
> **性质**：当前项目专用 Owner，不替代 `PRD` 与长需求清单

---

## 一、这份契约先解决什么

- 先让 `S2-05` 从"想追踪阅读历史"变成一条可开工、可验证、可交接的最小闭环。
- 当前只承接 **已索引文件的阅读行为记录**，不冒充完整用户行为分析系统。
- 最小接口定为：`POST /api/reading-history`（记录阅读）+ `GET /api/reading-history`（查询历史）+ `GET /api/reading-history/continue`（继续阅读建议）

---

## 二、当前范围边界

### 当前支持

- 记录用户对 **已索引文件** 的阅读行为（文件ID + 时间 + 次数）
- 查询阅读历史（按最近阅读时间排序，支持条数限制）
- 提供继续阅读建议（取最近阅读但可能未完成的文件）

### 当前不冒充已有

- 不追踪页面停留时长（duration 字段预留但不采集）
- 不做阅读行为分析、阅读习惯画像
- 不做跨设备/跨用户同步
- 不把"继续阅读建议"说成"智能推荐系统"

---

## 三、数据存储契约

### 存储方案

JSON 文件，路径：`app/rag_app/data/reading_records.json`

### 记录结构

```json
{
  "file_id_1": {
    "file_id": "example.md",
    "file_name": "示例文件.md",
    "first_read_at": "2026-05-12T14:00:00",
    "last_read_at": "2026-05-12T14:30:00",
    "read_count": 3,
    "total_read_seconds": 0
  }
}
```

### 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `file_id` | `string` | 来自 `GET /api/kb/files` 的已索引文件 ID |
| `file_name` | `string` | 文件显示名 |
| `first_read_at` | `string` | 首次阅读时间（ISO 8601） |
| `last_read_at` | `string` | 最近阅读时间（ISO 8601） |
| `read_count` | `number` | 阅读次数 |
| `total_read_seconds` | `number` | 预留字段，当前为 0 |

## 四、请求/响应契约

### 4.1 记录阅读行为

**Endpoint**：`POST /api/reading-history`

**Request JSON**：

```json
{
  "file_id": "example.md"
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `file_id` | `string` | 是 | 来自 `GET /api/kb/files` 的已索引文件 ID |

**Response JSON**：

```json
{
  "status": "ok",
  "file_id": "example.md",
  "read_count": 3
}
```

### 4.2 查询阅读历史

**Endpoint**：`GET /api/reading-history`

**Query 参数**：

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `limit` | `number` | 20 | 返回条数上限 |
| `sort_by` | `string` | `last_read_at` | 排序字段（`last_read_at` / `read_count` / `first_read_at`） |

**Response JSON**：

```json
{
  "records": [
    {
      "file_id": "example.md",
      "file_name": "示例文件.md",
      "first_read_at": "2026-05-12T14:00:00",
      "last_read_at": "2026-05-12T14:30:00",
      "read_count": 3,
      "total_read_seconds": 0
    }
  ],
  "total": 5
}
```

### 4.3 继续阅读建议

**Endpoint**：`GET /api/reading-history/continue`

**Response JSON**：

```json
{
  "suggestions": [
    {
      "file_id": "example.md",
      "file_name": "示例文件.md",
      "last_read_at": "2026-05-12T14:30:00",
      "reason": "最近阅读过，建议继续"
    }
  ]
}
```

---

## 五、最小验收

1. `POST /api/reading-history` 对 1 个已索引文件返回 `200`，记录数 +1
2. `GET /api/reading-history` 返回 `records` 数组和 `total` 计数
3. `GET /api/reading-history/continue` 返回 `suggestions` 数组
4. 重复 `POST` 同一 file_id 时，`read_count` 递增
5. 前端页面能展示阅读历史和继续阅读建议
6. 不把"继续阅读建议"误报成"智能推荐系统"
