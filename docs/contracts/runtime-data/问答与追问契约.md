# AI知识库 — 智能问答 / 流式 / 追问契约

> **用途**：固定 `智能问答`（当前文档/全库/跨文档/联网）相关 API 的最小请求、响应与 SSE 事件结构
> **更新日期**：2026-08-13
> **状态**：active-owner
> **涉及路由**：`POST /api/gemini/chat`、`POST /api/gemini/chat/stream`、`POST /api/gemini/followups`

---

## 一、POST /api/gemini/chat（非流式问答）

请求：
```json
{
  "messages": [{"role": "user", "content": "问题"}],
  "documentContext": [{"id": "物理文件名"}],
  "webSearchEnabled": false
}
```

响应：
```json
{
  "text": "回答（Markdown，可含 GFM 表格）",
  "groundingSources": [{"title": "网页标题", "uri": "https://..."}],
  "evidence": [{"text": "原句", "file_name": "书名", "physical_name": "文件名",
                "page_number": 301, "chunk_index": 158}]
}
```

- `groundingSources` 仅联网模式返回真实网页源；本地模式恒为空。
- `evidence` 为与回答直接相关的原文句子（含《书名》页码/段落定位），供前端"引用直达原文"。

## 二、POST /api/gemini/chat/stream（SSE 流式问答）

请求体同非流式。响应为 `text/event-stream`，每事件一行 `data: <json>\n\n`：

| 事件 type | 载荷 | 说明 |
|-----------|------|------|
| `meta` | `{mode: "rag" \| "local-fallback"}` | 开始标记 |
| `sources` | `{sources: [...], evidence: [...], domain}` 或 `{groundingSources: [...]}` | 本地来源/网页源 |
| `chunk` | `{content: "增量文本"}` | 逐字输出 |
| `text` | `{content: "统计回答", stats: true}` | 统计类问题直答（无 chunk） |
| `done` | `{}` | 正常结束 |
| `error` | `{content: "原因"}` | 失败结束 |

## 三、POST /api/gemini/followups（追问建议）

请求：
```json
{"question": "用户问题", "answer": "已有回答"}
```

响应：
```json
{"followUps": ["追问1", "追问2", "追问3"]}
```

- 生成失败/无 LLM 客户端时返回空数组，不报错。
- 前端点击"生成追问建议"触发，不阻塞主回答。

## 四、契约边界

- 本契约只定义问答链路，不覆盖总结/脑图/卡片等其他 LLM 端点（见各自契约）。
- 统计类问题（多少字/页/章）由后端全文统计直答，走 `text` 事件或非流式 `text` 字段。
