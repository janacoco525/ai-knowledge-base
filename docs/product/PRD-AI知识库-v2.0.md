## 一、产品定位

### 1.1 一句话描述
AI知识库是一个面向个人用户的本地知识管理工具，通过文件夹扫描自动入库、RAG问答、知识图谱可视化和自动概念关联，将散落文件变成可检索、可关联、可发现的知识网络。

### 1.2 v2.0 架构升级

| 维度 | v1.x（旧） | v2.0（目标态） |
|------|-----------|--------------|
| 页面架构 | 5个独立HTML，顶部nav标签导航 | **10页统一外壳**：固定侧栏(240px) + 面包屑 |
| 设计系统 | 2个色值 | **完整设计令牌**：Primary 7级 + Neutral 9级 + 排版/间距/组件 |
| 导航模式 | 各页面独立nav，切换丢失上下文 | **侧栏常驻** + 面包屑定位 + 页面间渐进迁移 |
| 功能分层 | 无 | **四级架构**：核心层/分析层/工具层/系统层 |
| 首页定位 | "欢迎卡+搜索框+推荐" | **仪表盘**：状态卡片+变更提醒+快捷操作+文档列表 |

### 1.3 核心差异化价值

| 价值 | 说明 |
|------|------|
| 知识图谱可视化 | 交互式概念网络，拖拽/hover/双击，支持文件级聚焦 |
| 持续积累+自动关联 | 跨会话知识积累，多文件夹变更检测与自动刷新 |
| 知识缺口提示 | "你读了A和B，但还缺C" |
| AI语义对比 | 非逐行diff，语义级变更描述 |

## 二、目标用户

| 用户画像 | 典型场景 |
|---------|---------|
| 开发者 | 扫描技术文档文件夹，AI问答+知识图谱发现概念关联 |
| 知识工作者 | 管理阅读笔记/行业报告，AI总结+对比+缺口提示 |
| 学生/研究者 | 文献资料整理，自动构建知识框架树 |

**v2.0 特别关注**：非技术知识工作者。原型评审发现当前示例数据偏技术向（全是开发场景），v2.0需在页面文案和示例中降低技术术语密度。

### 3.1 全局导航：固定侧边栏

```
侧边栏结构（240px，position:fixed，背景 #f5f5f4）：
├── 品牌区（AI知识库 logo + 名称）
├── 主导航 section
│   ├── 仪表盘（Dashboard）
│   ├── 文档管理（Documents）

│   └── 知识网络（Graph）

│   ├── 阅读记录（Reading History）
│   └── 设置（Settings）

```

### 3.2 导航行为
- 点击 nav-item → `navigateTo(page)` → 跳转对应 HTML 页面
- 目标页加载 → `loadSidebar('page-name')` → 侧栏高亮当前项 + 注入面包屑
- 面包屑格式：`首页 / 当前页`
- 侧栏加载后自动隐藏旧顶部导航栏链接（`.nav-links`）

| 语义色 | success #22c55e / warning #f59e0b / error #ef4444 |
| 字体 | `--font-sans: Inter, PingFang SC, Noto Sans SC, Microsoft YaHei` |
| 字号 | 12px/13px/14px/16px/18px/22px/26px/28px |

| 间距 | 4px基准，8px步进：`--space-1~12` (4px → 48px) |
| 圆角 | sm 6px / md 8px / lg 12px / btn 8px |
| 阴影 | card: `0 1px 3px rgba(0,0,0,0.04)` |

### 4.2 组件规范

| 组件 | 关键规范 |
|------|---------|
| 按钮 | 8px圆角 / min-height 36px / padding 8px 16px / font-weight 500 |
| 输入框 | 8px圆角 / height 40px / focus: 0 0 0 3px primary-100 |
| 卡片 | 12px圆角 / 标准阴影 / padding 24px |

| 禁止 | 原因 |
|------|------|
| 纯黑 #000000 | 用 neutral-900 #1c1917 |

| 靛紫色大面积背景 | primary仅用于交互元素 |
| 混用冷暖灰色系 | 全文统一Warm Stone |
| 阴影过重 | 不超过 `0 16px 48px` |

## 六、页面交互规格

### 6.1 仪表盘 (index.html)
- **状态卡片**：3列（扫描文件夹数/文档总数/上次扫描），点击跳转文档管理
- **变更提醒条**：黄色banner，检测到新/变更文件时显示，含"立即更新"按钮（60s超时保护）
- **快捷操作**：3卡片（管理文档/智能问答/知识网络），点击跳转
- **最近文档**：最多8条，含文档名/段落数/域名

### 6.2 文档管理 (knowledge.html)
- **Tab分离**：文档库 | 添加文档
- **文档库**：域名筛选标签 + 文档列表 + 详情面板（元数据/段落预览/内嵌图谱按钮）
- **添加文档**：路径标签（可点击选中）+ 文件夹输入+扫描 + 扫描全部/刷新变更/添加路径
- **空状态**："还没有文档，切换到「添加文档」开始"

### 6.3 智能问答 (chat.html)
- **内容区**：max-width 720px 居中
- **文档多选**：标签组件，支持多选（独立标签 + "全部文档"默认）
- **消息流**：用户右对齐紫色浅底 / AI左对齐白底 + 可展开来源引用面板
- **历史记录**：输入框上方小标签行（最多5条），点击重问
- **输入区**：输入框 + 发送按钮（Enter发送）

### 6.4 知识网络 (graph.html)
- **全宽SVG交互**：节点拖拽/hover高亮/选中染色
- **控制面板**：显示模式/节点数量/排序策略
- **文件聚焦**：支持 `?file=xxx` URL参数，仅展示该文件相关图谱
- **图例**：节点类型/颜色标注

### 6.5 分析工具页（P1，已落地，侧栏入口已建）
- cards.html — 知识卡片浏览/搜索
- analysis.html — AI结构化摘要
- knowledge-tree.html — 知识框架树
- diff.html — 两文档语义对比

### 6.6 系统页（P2）
- reading-history.html — 阅读记录追踪
- settings.html — API配置/扫描路径管理
