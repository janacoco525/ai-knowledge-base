# 数据迁移指南（换电脑 / 换浏览器）

> 面向使用者的操作说明，不含代码。系统会自动把标注、图谱、知识卡、词条等同步到
> 服务端数据目录（`app/rag_app/data/user_state.json`），所以"复制文件夹"就能带走全部数据。

## 一、你的数据都存在哪

| 位置 | 内容 | 换电脑时 |
|---|---|---|
| 服务端文件夹（运行服务的电脑） | 文档源文件（`data/uploads/`）、索引（`chroma_db/`）、聊天记录（`chat_history.db`）、图谱概念卡、标注/图谱/卡片/词条自动同步文件（`user_state.json`）、配置（`.env`） | 复制文件夹即可带走 |
| 浏览器 | 知识卡、词条、图谱、文件夹、标注等（已自动同步到服务端） | 首次打开新页面会自动恢复，无需手动操作 |

## 二、方案一：整机迁移（推荐，复制文件夹）

1. **停止服务**（关掉后端/前端进程）。
2. 把以下三个位置**复制到新电脑的相同位置**：
   - `chroma_db/`（项目根目录，索引）
   - `app/rag_app/data/`（上传文档、聊天库、概念卡、`user_state.json`）
   - `.env`（扫描路径与模型配置）
3. 新电脑安装依赖并**启动服务**。
4. 打开页面：文档、索引、聊天、图谱、卡片、标注**自动恢复**，无需额外操作。

> 提示：如果文档源文件本来就在你自己的文件夹里（例如电子书目录），那份文件按原路径
> 放好即可；`data/uploads/` 是入库副本，两者都可以带上。

## 三、方案二：手动导出 / 导入（换浏览器、断网、或想留一份保险）

1. 在**旧设备**：设置管理 → **数据迁移** → **导出本地数据**，得到一个 JSON 文件。
2. 把这个 JSON 带到**新设备**（U盘/网盘/微信文件传输均可）。
3. 新设备打开页面：设置管理 → **数据迁移** → **导入恢复** → 选择该 JSON → 确认 → **刷新页面**。

注意事项：
- 导入会**覆盖当前浏览器的本地数据**，导入前如果旧设备数据还有用，先确认已导出。
- 导出只包含浏览器侧数据（知识卡/词条/图谱/文件夹/标注），**不含服务端文档与索引**——那些跟着文件夹走（方案一）。

## 四、常见问题

- **换电脑后打开页面是空的？** 确认 `app/rag_app/data/user_state.json` 已随文件夹复制过去；首次打开会自动载入。
- **两台电脑同时用会怎样？** 后保存的一方覆盖先保存的一方（个人使用场景足够）。
- **我想彻底不依赖浏览器？** 不需要——浏览器数据已自动同步到服务端文件夹，复制文件夹即可；手动导出/导入只是保险。
- **`user_state.json` 是怎么来的？** 首次打开页面后由系统自动生成，无需手工创建。
