# AI知识库 — 术语表

> ⛔ **所有模型必须在修改代码前读取此表。混淆术语 = 修错代码 = 浪费时间。**

## 核心功能区分（最容易混淆的三组）

| 中文术语 | 英文 | 组件文件 | API 端点 | 数据结构 | 可视形态 |
|---------|------|---------|---------|---------|---------|
| **知识图谱** | Knowledge Graph | `KnowledgeGraph.tsx` | `/api/graph/data` | `{nodes: [...], edges: [...]}` | 网状图（节点+连线，力导向/辐射式） |
| **知识脑图** | Mind Map | `MindMap.tsx` | `/api/gemini/generate-mindmap` | `{topic: "...", children: [{topic, children}]}` | 树状图（根→二级→三级，层级展开） |
| **知识卡片** | Knowledge Cards | `KnowledgeCards.tsx` | `/api/cards` | `{concept, summary, related_concepts}` | 卡片列表 |

### 图谱 ≠ 脑图

```
图谱 (Graph):     A ── B          脑图 (MindMap):        根
                  │  ╱ │                                  ├── 主题1
                  C ── D                                  │   ├── 要点a
                网状结构                                   │   └── 要点b
                                                          └── 主题2
                                                              └── 要点c
                                                        树状结构
```

## 组件层级

```
GraphPanel.tsx  (共用容器，在"知识网络"tab)
├── KnowledgeGraph.tsx   ← 知识图谱 (tab: "network")
└── MindMap.tsx          ← 知识脑图 (tab: "mindmap")
```

## API 区分

| 想做的事 | 调这个 API | 不是这个 |
|---------|-----------|---------|
| 查看文档实体关系网络 | `GET /api/graph/data` | ~~`/api/gemini/generate-mindmap`~~ |
| 生成文档层级结构脑图 | `POST /api/gemini/generate-mindmap` | ~~`/api/graph/data`~~ |
| 获取概念卡片 | `GET /api/cards` | — |

## 前端状态区分

| 状态变量 | 所属组件 | 含义 |
|---------|---------|------|
| `graphNodes` / `graphEdges` | GraphPanel → KnowledgeGraph | 图谱的节点和边 |
| `mindmaps` / `mindmapData` | GraphPanel → MindMap | 脑图的树形数据 |
| `graphSubTab` | GraphPanel | 当前显示 "network"(图谱) 还是 "mindmap"(脑图) |

## 文件清单

| 文件 | 职责 |
|------|------|
| `frontend/src/components/KnowledgeGraph.tsx` | 图谱 SVG 渲染（节点+边+拖拽+hover） |
| `frontend/src/components/MindMap.tsx` | 脑图 markmap 渲染（层级树+折叠+缩放） |
| `frontend/src/components/GraphPanel.tsx` | 图谱和脑图的共用容器（tab切换+数据管理） |
| `app/rag_app/routes/graph.py` | 图谱后端 API（/api/graph/*） |
| `app/rag_app/routes/llm_ops.py` | 脑图后端 API（/api/gemini/generate-mindmap） |
